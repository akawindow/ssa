# 第十五轮：只规范化选择器看到的成分

## 锁定的问题与规则

第十四轮观察到弱成分权重接近选择器的零输入响应。用户要求继续，本轮只检验：选择器侧的幅值差异是否妨碍区分成分，并能否影响受控分类收益。

执行源码及协议在训练前提交 `8677eb5`。每个成分c先构造 `v=c/max(RMS(c),0.001)`，共享CNN和选择头看v、生成p；真正合成仍为 `sum(p*c)`，下游分类器看原幅值重构。既不把规范化成分直接合回去，也不单独把重构输出统一尺度。无去均值，不传入额外能量特征，不同时修改CNN、头max-norm、偏置或损失。

0.001是标准化原始信号单位中的固定工程下限，将放大限制为1000倍，并让数值残差约10⁻¹⁵ RMS保持接近零。不是数据驱动选出的最优阈值，也没有检验不同阈值的敏感性。低于下限的成分不保证单位RMS；不能把本轮描述为彻底消除所有幅值差异。

三个种子42/43/44各重新训练一个任务分支，共同原始预训练检查点、初始化、批次、2400次头/分类器更新、60轮预算和学习率调度均与第十三轮一致。共享CNN仍参与交替更新，不冻结。主要选模继续用selection CE（含epoch0），主评价仍为60轮预算；40/50轮最佳及40/50/60终态作完整补充，不按评价成绩挑预算。

原始、固定0.5、固定SSA、学习全局缩放和原任务SSA对照，复用第十三轮已经完成的同预算模型，不假称本轮重新训练过这些对照。逐项核对配置、初始模型哈希、批次哈希及优化器更新计数，来源文件保持不变。没有用旧任务模型继续适配新输入，而是从相同预训练状态重新完成本轮60轮。

数据仍为FordA官方TRAIN内部2520拟合/540选模型/541评价；无人工污染、无SRD，官方TEST不使用。全部三个新分支训练完成后才计算内部评价成绩。评价此前已被探索，本轮也是由旧结果启发的机制试验，不是新的独立确认。

## 核验与复现

43项检查通过，包括规范化后的保留权重对高于下限的成分正比例缩放不变、原幅值加权和仍正确、零输入有限、关闭规范化时默认路径与旧运算一致。已有梯度反馈、阶段隔离和预算一致性检查也保留。

训练前另运行 `verify_classification.py` 重载全部旧18模型，验证默认未规范化路径的54组划分预测复现。新模型保存后再次重载核对selection CE和参数哈希；后续独立核验及检查点评分分别保留，不修改来源运行。

```powershell
python scripts/run_selector_normalization.py --out runs/selector_rms_new
python scripts/verify_classification.py --run runs/selector_rms_new --out runs/selector_rms_new_verification --reference-run runs/classification_60_initial
python scripts/analyze_selector_normalization.py --run runs/selector_rms_new --out runs/selector_rms_new_budget_analysis
```

本地需保留第十三轮权重、SSA缓存及原始TRAIN文件。数据与权重不进入GitHub，原运行目录不覆盖。

## 解释边界

规范化减少了选择器看到的成分幅值差异，也改变了它与原预训练特征之间的分布关系，可能丢失有用幅值信息或放大弱变化。即使权重差异变大，也不自动代表分类更好；即使分类更好，也不等于物理去噪。若未改善，不能仅据一个RMS下限否定所有幅值控制方案。无论结果正负，本轮不追加阈值搜索或同时解除约束。

## 60轮主结果

全部三个分支完成60轮、头/分类器各2400次更新。最佳轮次58/42/58，均按selection CE成对恢复。主运行1470.22秒（约24.5分钟），含三个新分支训练、评分和重构统计，不包含训练前旧模型核验；CPU、数值线程1。

| 种子 | 旧权重的样本内标准差 | 新权重的样本内标准差 | 旧形状残差RMS/原始RMS% | 新形状残差RMS/原始RMS% |
|---|---:|---:|---:|---:|

| 43 | 0.0149 | 0.1020 | 0.94 | 6.17 |
| 44 | 0.0134 | 0.0466 | 1.03 | 2.85 |

形状残差指重构与每样本最接近整体缩放之差，不是去噪误差。可以确认本次改动让选择与重构行为明显改变，但差异更大不自动代表更好。

三个种子拟合平均权重中，C3/C4从约0.636/0.640变为0.707/0.730；C30/C32从约0.673/0.673变为0.516/0.518。这个方向与此前C3/C4较有类别信息的线索相符，但原探测使用旧编码器；本轮未重新训练99个成分探测器，不能直接移用旧分数来证明新权重与新特征的信息排序已正确。成分仍有互补、冗余和相消，不据权重大小认定物理噪声。

## 本轮判断

这是当前同预算分类比较中一次小幅正向平均结果，支持继续检验选择器侧幅值处理，而不是已经证实插件有效。不能据此宣布第十四轮找到了唯一失败原因，也不建议立即接SRD、人工污染或更换数据。下一步更有价值的是保持本协议和阈值不变，追加预先固定的训练种子验证稳定性；若增加新划分，需同时重跑全部对照，不能只挑新方法受益的划分。该重复验证尚未执行，官方TEST继续封存。
