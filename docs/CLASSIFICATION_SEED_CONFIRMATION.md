# 第十六轮：三个新种子的配对重复验证

## 在看到新结果前锁定

用户授权继续新增种子45/46/47。执行源码与协议预先提交 `843130e`，配置为 `configs/classification_seed_confirmation.json`。本轮不是根据旧结果继续改阈值，而是固定第十五轮方案，检查训练随机性的稳定性。

每个新种子从头训练一个共同原始输入CNN：仍为最大40轮、耐心10、按selection CE恢复最佳状态。之后从同一状态分别训练原始输入、原任务SSA、选择器侧RMS规范化SSA三组，各60轮/2400次分类器更新；两个选择头各额外2400次更新。三个分支批次顺序、分类器优化器及选模规则匹配，任务分支仍交替更新共享CNN。原始输入对照也获得额外训练预算，不只比较共同预训练。

保持FordA TRAIN内部2520/540/541划分、SSA嵌入32、全部成分加数值残差、CNN、max-norm0.25、RMS下限0.001、学习率调度和标签不变。不加人工污染/SRD，不使用官方TEST。不把成分规范化直接用于合成，重构仍为原幅值成分的加权和。

三个种子用独立本地Python进程并行，数值线程各为1，随机状态不共享；每个进程只训练、不评分内部评价。九个分支及三个预训练全部完成、通过预算/哈希核验后，才启动统一评分。各进程新输出目录互不覆盖；旧运行只读并核对哈希。

预定主要报告新增三次的规范化SSA减原始输入配对差；旧任务作为次级对照。旧42/43/44与新45/46/47分开报告，再给出全部六次汇总，不只保留较好的种子。按selection CE选出的最佳状态为主，真实第60轮终态另报，不依据内部评价重新挑轮数或种子。

同一评价数据被多次探索，增加种子只能检查训练随机性，不等于增加独立数据或完成跨数据集确认。六个种子共用541条评价样本，不能按6×541当成独立测试样本宣称显著。

## 代码位置与运行

本工程目录下：`ssa_task_srd/`为算法，`scripts/`为运行入口，`configs/`为参数，`runs/`为本地大结果，`docs/`为研究记录。

一键执行预定三个种子并统一评分（Name必须未使用）：

```powershell
./scripts/run_seed_confirmation.ps1 -Name seed_confirmation_new
```

仅训练某一个已固定种子：

```powershell
python scripts/run_seed_confirmation.py --seed 45 --out runs/confirmation_new_seed45
```

统一评分前，必须具备三个种子的完整新输出：

```powershell
python scripts/summarize_seed_confirmation.py --jobs runs/confirmation_new_seed45 runs/confirmation_new_seed46 runs/confirmation_new_seed47 --out runs/confirmation_new_summary
```

预训练/训练状态、模型权重、logits及完整日志保留本地；代码、协议和小型结果进入GitHub。需要第十三/十五轮的本地参考结果及FordA TRAIN与SSA缓存，全新克隆仓库不包含这些大文件。

## 核验

运行前7项分类检查通过，包含任务梯度与阶段隔离、预算匹配、长短训练前缀、规范化重构幅值和零输入、默认路径兼容等检查。每个种子新预训练选择状态保存并由三分支共用；实际初始权重、批次哈希、分类器更新次数及参数数目逐项匹配。

评分程序重载预训练和全部分支，检查保存权重摘要与selection CE；真实终态另行重载并核对该轮selection CE。评分只写新汇总目录，完成后再核对训练输出与历史参考文件哈希，保留所有旧结果。

## 实际完成情况

三个新共同预训练均完整40轮、1600次更新，最佳轮次40/39/40。九个协同分支均完整60轮、各2400次分类器更新；六个任务头另各2400次更新。三个组内初始权重/批次摘要一致，阶段隔离核验通过。新增主训练代码未改变；评分前补充提交 `4a2b2f3` 仅将历史预训练分数纳入汇总，避免“全部六次”表中预训练行只有新三次，协议和主要比较不变。

并行启动至统一评分完成墙钟614.63秒，约10.2分钟。各进程的耗时有重叠，不能相加后当成本轮墙钟，也不能与旧串行耗时直接解释为模型复杂度变化。输出为三个 `runs/seed_confirmation_initial_seed45/46/47/` 训练目录和 `runs/seed_confirmation_initial_summary/` 评分目录。

统一评分重载12个所选模型（3个共同预训练+9个分支），另重载9个实际第60轮终态，共54组划分评分。所有权重摘要、selection CE均核对，311个训练/历史来源文件保持不变。没有使用官方TEST。

## 主要结果：先看新增三次，再看全部六次

均为预先约定的selection CE最佳模型在同一内部评价集的准确率%。

| 训练种子组 | 原始输入 | 原任务SSA | 规范化SSA | 规范化−原始，百分点 |
|---|---:|---:|---:|---:|
| 旧42/43/44 | 90.33 | 90.02 | 90.51 | +0.18 |
| 新45/46/47 | 89.65 | 89.46 | 89.59 | −0.06 |
| 全部六次 | 89.99 | 89.74 | 90.05 | +0.06 |

全部六次样本标准差：原始0.83个百分点、原任务0.81、规范化0.69。均值差远小于训练种子间波动，不据此作统计显著结论。旧结果保持不变，新种子的总体成绩较低也不代表代码退化：种子同时改变了预训练、批次顺序等训练随机性，且本轮各方法在组内仍严格配对。

| 种子 | 原始判对/541 | 原任务判对/541 | 规范化判对/541 | 规范化−原始净判对 |
|---|---:|---:|---:|---:|
| 42（旧） | 487 | 487 | 491 | +4 |
| 43（旧） | 488 | 483 | 489 | +1 |
| 44（旧） | 491 | 491 | 489 | −2 |
| 45（新） | 479 | 479 | 483 | +4 |
| 46（新） | 491 | 489 | 489 | −2 |
| 47（新） | 485 | 484 | 482 | −3 |

新增三次是一胜两负；全部六次三胜三负。新三次相对原任务SSA净判对+4/0/−2，全部六次相对原任务三胜一平两负，平均约+0.31个百分点；不能称相对原任务也已稳定改善。

净判对在六次重复中合计只多2次，且各次使用同一批样本，不是2个独立新样本的结论。完整新样本判对转换计数见 `results/seed_confirmation/new_paired_differences.csv`。

## CE与终态补充，不能替换主要口径

| 种子组 | 原始评价CE↓ | 原任务评价CE↓ | 规范化评价CE↓ |
|---|---:|---:|---:|
| 新三次 | 0.26135 | 0.26202 | 0.25442 |
| 全部六次 | 0.25453 | 0.25586 | 0.24965 |

规范化的平均CE仍更好，说明概率预测方面可能存在收益；但CE与argmax准确率不是一个指标，不能在主要准确率优势未重复后临时改用CE宣布总体成功。该概率现象可保留为另一个有待确认的研究问题。

新增三次实际第60轮终态准确率：原始88.97%、原任务89.22%、规范化89.71%。终态对规范化更有利，但不能看到结果后改掉预先锁定的selection CE选模口径。所选最佳轮次原始60/59/59、原任务60/59/52、规范化49/59/54，所有组仍完整执行60轮。

## 当前判断

第十五轮的小幅准确率优势没有在新三次中稳定重复；六次总体接近原始输入，不能把规范化SSA视为已验证有效的分类插件。它确实改变选择行为，且平均CE改善，但仍未建立主要准确率的稳定增量。不能反过来据此否定全部SSA、任务驱动框架或所有分类数据。

建议结束当前配置的追分，不继续因均值接近就调RMS下限、追加轮数或挑种子。后续如继续，应先明确新假设与目标（例如何种干扰可被分解、选择后是否保留类别信息），重新锁定干预和匹配对照；不在已探索评价集上无止境寻找正结果。没有执行新的阈值搜索、网络变更或新数据实验，官方TEST继续封存。
