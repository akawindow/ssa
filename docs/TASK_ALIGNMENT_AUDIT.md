# TASK 迁移代码核对：哪些来自原实现，哪些是本工程假设

本轮按用户要求继续做单变量实验，并回到本机已经复现运行的 TASK 代码检查设计。原始 EEG 工程只读，未修改或重新分发；本轮继续使用 Tetouan 原始观测，不加人工污染、不接 SRD。

**核对结论：当前工程迁移了 TASK 的交替优化机制，但前六成分加残差、近乎全保留的初始化、小样本子集，以及独立 Ridge 评价，都是额外设计。它们需要分别验证，不能当成 TASK 论文已经支持的设置。** 本轮未发现交替更新阶段混淆或参数意外冻结，已确认若干设计与评价上的风险。

## 核对的本地文件

本机 `D:/cjx/paperstudy/eegdenoise/official/` 下：

该目录已有 baseline/framework 日志及三个被试的结果文件。本轮依据的是本机文件，而非假定它们与当前线上主分支逐字相同；执行元数据保存了前四个文件的 SHA256。官方来源为 [TASK 作者仓库](https://github.com/leizheng2005/Task-Oriented_Learning_for_Automatic_EEG_Denoising)。本工程没有把作者代码或权重上传到自己的仓库。

## 已正确迁移的核心机制

| TASK 本地代码机制 | 当前迁移实现与核验 |
|---|---|
| 先预训练任务模型，再从中提取成分特征 | 预训练预测代理，复用同一特征层；跨实验核验预训练权重相同 |
| 所有成分共用一个 sigmoid 选择头 | 同一个 33 参数头处理全部成分；145 组也不增加头参数 |
| 选择阶段由重构后的任务损失监督，只更新选择头 | 代理和特征层逐参数保持不变，选择头确实更新 |
| 第二阶段更新任务模型及共享特征 | 代理和共享层确实更新，选择头保持不变 |
| 第二阶段复用第一阶段产生的重构 | 使用更新选择头之前缓存的重构，显式截断跨阶段梯度 |
| 独立优化器、AMSGrad、梯度裁剪 | 两套 AdamW/AMSGrad，梯度范数裁剪 1；更新步数由实际批次数计算 |

当前训练是预测迁移：MLP 代替 EEGNet、预测 MSE 代替分类交叉熵。即便交替顺序一致，也不能称为完整 EEG TASK 复现。

## 本工程额外假设与处理

| 发现 | 为什么值得检查 | 本轮动作 |
|---|---|---|
| 前六单成分＋一个大残差组 | 原代码按通道数提供全部成分；本工程把许多不同结构压进同一权重。第六轮也发现候选对会被这个边界分开 | 对比 7 组与 145 组，完整分解提供给同一个选择头，不预先判定后续都是噪声 |
| 头偏置为 4，且没有范数约束 | 偏向全保留是本工程引入的保护性初始化。零特征时 sigmoid(4)约为0.982，局部斜率约0.0177；零偏置对应0.5和0.25。但真实输出还取决于特征与核权重 | 与本地 TASK 的零偏置＋max-norm 0.25 设置对照；记录实际初始化权重与 sigmoid 斜率 |
| 36/12 个窗口的工程子集 | 不能据此稳定判断方法效果，尤其输入432维 | 本轮改用当前划分内全部可用日步长窗口，251训练／54验证；所有新组一致 |
| 代理随协同训练变好，没有等更新次数的原始输入对照 | 改善可能来自继续训练，而非成分选择 | 每种子增加相同初始化、批次、优化器和480次更新的原始输入代理对照 |
| 固定 alpha 的 Ridge 对输入缩放敏感 | 近似一致的保留权重可能仅改变整体幅度和有效正则化，不能自动解释成去噪 | 加训练权重均值的常数缩放对照，以及正则化补偿的恒等核验 |
| 只拿 Ridge 作下游，未充分检查简单预测基线 | 击败某一个设置不代表任务上已有竞争力 | 加昨天同一时刻值的持久性预测，不需要训练 |
| 原始输入被叫作 reference，处理差被输出为 history_rmse | 没有干净真值；变得更接近输入并非去噪质量提升 | 本轮公开结果只使用预测MAE/RMSE，处理差解释为改动幅度；保留历史字段兼容但不作为恢复准确率 |

上述设置并非全部都是代码错误。例如偏向全保留可能有助于避免损伤输入，全部成分也可能增加困难；需要实验判断，不能把“更像原代码”直接当成更有效。

## 不应照抄的原实现细节

1. 本地 TASK 脚本里的通道64、样本480、特征维240是对应 EEG 数据的接口设置。单变量预测不能只换数据后继续使用这些常数。
2. 本地学习率调度按每轮约两批写成 `epochs * 2`。本轮251条训练历史、batch=8，每轮32批，应计算15×32=480步；照抄会使调度提前结束。
3. 本地 `Component_selection_sigmoid.call` 本身调用原始输入分类器；重构成绩通过 `eval_model_sigmoid` 计算。阅读时必须跟踪实际训练和测试入口，不能只看 `call` 就认定已评价去噪。本工程的任务 `call` 明确执行加权重构。
4. 本地训练保存验证最好和指定轮数权重，`test_framework.py` 实际载入 `epoch={epochs}.h5`。本工程则按验证代理MSE选择同一轮的代理与头共同恢复。这是明确的评价协议差异，本轮不将其伪装成逐项复现。
5. 原 EEGNet 含批归一化和卷积，当前 MLP 没有这些结构。相同 sigmoid 初始化造成的幅度变化，对两种代理未必有相同影响。本轮保持MLP不变，避免一次改太多因素。

仍未充分验证的设置包括历史432、嵌入144、隐藏特征32、Ridge alpha=1及训练预算。本轮没有把它们称为最优。选择头核初始化种子仍固定731，以保证成对比较；三个训练种子主要改变代理初始化及批次顺序，没有覆盖所有头初始化随机性。TASK式头仅指选择头的零偏置与范数约束，没有移植原分类输出层的约束或整个EEGNet。

## 本轮对照设计

执行前记录 [task_alignment_protocol.json](../configs/task_alignment_protocol.json)，源码提交 `00091ea`。

| 案例 | 提供给选择器的成分 | 选择头偏置 | 选择头核范数约束 |
|---|---|---:|---|
| coarse_current | 前6＋精确残差，7组 | 4 | 无 |
| full_current | 全144＋数值残差，145组 | 4 | 无 |
| coarse_task_head | 前6＋精确残差，7组 | 0 | 0.25 |
| full_task_head | 全144＋数值残差，145组 | 0 | 0.25 |

各42/43/44三个种子，共12次协同训练。头设置这一因素同时改变偏置和范数约束，**只能判断这组设置的效果，不能单独归因于偏置或约束**。成分因素则在每种头设置内分别比较。

所有组共享：单变量数据、相同训练/验证窗口、标准化、432→144预测、MLP结构、同种子预训练权重、同种子批次顺序、15轮协同、480次头更新与480次代理更新。头33参数、代理18,608参数，不因成分组数变化。145组增加成分打分计算，不等于增加独立可训练头。

另执行固定前六、固定前七、既定C6/C7配对保护规则、全成分恒等重构、原始输入和昨日持久性基线。配对规则直接使用第六轮阈值，不按本轮成绩调参。

每个种子的 `coarse_current` 额外运行原始输入代理对照，按第1至15轮验证MSE选取最好成绩；它与任务训练有同样的代理更新预算，单独记录，不被称为去噪方法。该案例的总学习耗时包含额外代理对照，不能直接作为四组纯训练速度比较。

独立 Ridge 为主要评价之一，统一float64/Cholesky、alpha=1，按处理后的训练历史各自拟合。其成绩不参与选择神经模型轮次。另报告联合代理及简单基线，避免只评价一个角度。

## 常数缩放核验如何解释

每次训练后，用**训练窗口**权重均值确定常数 s，所有历史统一乘以 s。没有从验证成绩寻找 s。

对于相同常数缩放，Ridge 若仍用 alpha=1，其等效正则化会变化；若同时把 alpha 改为 s²，则应恢复原始输入预测。后一个恒等关系有单元检查和本轮逐例数值核验。

这只是解释对照，不是提出新的去噪方法。若任务加权的成绩与常数缩放差不多，不能将提升全部归为精细的成分筛选；若超过它，也仍需排除其他因素和在留出数据确认。

## 结果与边界

实际数值、解释和下一步见 [本轮结果](TASK_ALIGNMENT_RESULTS.md)。新窗口集合、更新次数均与旧工程小样本不同，不能把跨轮数字变化全部归于新选择头或成分设置。

本轮验证集用于探索和神经检查点选择，未评价测试集；原始数据没有干净真值。完整成分、TASK式头设置或配对规则都不因设计合理就自动成为成功结果。
