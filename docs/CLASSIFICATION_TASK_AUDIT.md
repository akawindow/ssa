# 第十轮分类迁移与TASK的逐项核对

2026-10-20，用户问为什么没有提升、横向对照原TASK有哪些细节不同。本次为只读源码/论文核对和已有日志分析，没有新增训练，没有修改历史实验或原EEG工程。

## 先明确结论层级

第十轮实现了TASK式“预训练→共享任务特征→sigmoid成分加权→分类CE→交替更新”。但同时改变了数据、分解、网络、部分正则、尺度与选模型规则，是简化迁移试验，不能称为只把原TASK的ICA换成SSA。当前负结果只约束这一配置。

## 对照依据

- 论文版本：https://arxiv.org/html/2509.14665v1 ，重点III-B/III-C、IV-B3及表I。论文还报告原始EEG固有噪声条件，不能说它只靠人工加噪成立。
- 作者仓库：https://github.com/leizheng2005/Task-Oriented_Learning_for_Automatic_EEG_Denoising 。本次代码判断以本机只读 `D:/cjx/paperstudy/eegdenoise/official/` 文件为准，不假定与所有线上版本一致。
- 本工程执行版本 `7bc05dc`；配置 `configs/classification_protocol.json`；训练、模型与指标记录在 `runs/classification_initial/`，公开小报告在 `docs/results/classification/`。
- FordA噪声条件定义：https://timeseriesclassification.com/description.php?Dataset=FordA 。官方称典型运行条件下污染较少，并非保证毫无噪声。

## 关键差异

| 项目 | 原论文/本地TASK实现 | 本轮FordA分类 | 对结论的影响 |
|---|---|---|---|
| 数据 | EEG多通道；本地Cho2017为64×480；论文还含8通道及32通道数据 | 单变量，500点，故障症状分类 | 无法利用原多通道空间分离线索，不能把跨数据差异归因于损失函数 |
| 噪声 | 原始固有噪声及额外EOG/EMG条件分别评估 | 原始FordA，不加污染，无干净真值 | 尚未建立“存在可去除且有害的干扰”这一事实；原论文也有不加额外伪迹的结果 |
| 分解 | ICA/PCA/SVD直接处理通道×时间矩阵；每成分仍是多通道时空重构 | 一维序列→32×469轨迹矩阵SVD→对角平均；32基本成分+精确残差 | SSA同样用了SVD，但分解对象、可分离性和成分语义不同；不保证一个成分就是一种物理噪声 |
| 特征网络 | EEGNet：时间卷积、空间深度卷积、可分离卷积、BN、Dropout、池化 | 两层步长卷积、ELU、全局平均池化；无BN/Dropout | 是助手为小试验主动做的简化，尚未证明足够适合对SSA成分打分 |
| 共享特征 | 本地Cho2017配置Flatten后240维；保留头241参数 | GAP后32维；保留头33参数 | 各组内部匹配，但不是同一特征表达；GAP弱化绝对时间位置信息，不能先断言一定损伤FordA |
| 约束 | 保留头max-norm0.25；分类输出层也max-norm0.25；空间深度卷积约束1 | 仅迁移保留头max-norm0.25；分类输出无该约束 | 只对齐了选择头设置，未对齐整个网络正则；缺失约束是否导致负结果未验证 |
| 输入标准化 | 本地get_std_X在训练样本维计算channel×time逐位置均值方差 | 拟合输入的一个全局均值/标准差；FordA本身接近逐条z标准化 | 两者不等同；不应为了像原代码而未经验证照搬对齐EEG的逐位置尺度 |
| 训练轮数 | 论文MI/ME各50预训+50协同；SSVEP各500 | 40预训+10协同，本次三个预训练均完成40轮 | 当前是小预算设置；本轮每分支40批/轮、共400次下游更新，不能只比轮数断言训得少/多 |
| 调度 | 本地协同脚本用epochs×2写死Cosine总步数 | 按实际batch数算10×40=400 | 是明确适配，不应照搬写死常数；两者LR初值0.001、余弦alpha0.9、AMSGrad/裁剪1相同 |
| 预训练检查点 | 本地baseline_best_acc按验证准确率选择 | 按selection CE选择，显式恢复最优 | 学到的起点可能不同，但不能把一种选择准则先认定更好 |
| 协同检查点 | 本地同时保存最佳验证准确率和固定轮数；test_framework实际读取epoch=N | 取0..10最小selection CE，联合恢复分类器及头 | 不属于逐项复现；也没有使用评价集挑轮次 |
| 统计单位 | 论文按被试进行5折、6:2:2评价 | 官方TRAIN固定2520/540/541，三个训练种子，官方TEST封存 | 三种子不是三数据集/三独立划分，不与论文跨被试均值直接比数值 |
| 原始输入对照 | 检查到的本地test_baseline读取预训练best_acc；train_framework从该权重继续协同；这些入口未见等协同更新预算的raw继续训练分支 | 除预训练原始基线，另加同400更新的raw继续训练、固定半缩放和全局缩放 | 本工程主要问的是“相比多训练同样次数是否有额外贡献”。不能据局部脚本就断言作者从未做过任何额外对照，更不能借此否定其论文结论 |

## 已经一致、不是当前缺失的部分

1. 使用真实类别标签预训练，并从同一任务网络抽共享成分特征。
2. 所有成分共用sigmoid头，逐样本输出保留概率，按加权和重构；完整学习分支没有先丢掉前七之后的成分。
3. 选择阶段只更新头，代理和共享特征不变；代理阶段更新共享特征和分类头，保留头不变。
4. 代理阶段使用选择头更新前缓存且截断梯度的重构，与本地原实现训练顺序一致。
5. 都以分类交叉熵监督。原实现one-hot+softmax CE，本轮整数标签+logits sparse CE，都是同一个分类目标的不同接口，不是改成了另一类损失。
6. 头偏置均为零、max-norm均为0.25。早期预测原型偏置4不属于当前分类实现。零偏置不等于所有初始概率都精确0.5，实际还受随机核和特征影响；全局缩放对照初值才严格为0.5。
7. TASK核心同样不要求干净重构损失或成分标签。本轮没有重构损失不构成“漏抄了原文监督”。

## 已有日志给出的具体线索

以下全部是selection CE，越低越好，不能混同为评价准确率。

| 种子 | 同预训模型原始输入、epoch0 | 刚接入任务重构、epoch0 | 任务分支选中CE | 原始继续训练选中CE |
|---|---:|---:|---:|---:|
| 42 | 0.26510 | 0.40744 | 0.27078 | 0.25975 |
| 43 | 0.26086 | 0.34714 | 0.26510 | 0.25233 |
| 44 | 0.25430 | 0.43174 | 0.26810 | 0.25010 |

输入改动在协同开始前就产生性能损失，随后有所恢复。这支持“预训练分类器对初始重构不适应”这一观察。纯0.5缩放的epoch0 CE也分别升为0.46327/0.37355/0.52172，表明当前分类器对整体幅值敏感。任务初始权重不完全均匀，尚不能把其损失跳升全部归为缩放；更不能仅据此认定BN缺失是确定原因。

本地原EEGNet包含BN且选择阶段training=False，分类器阶段training=True。本轮删除BN原为减少首轮实现状态的复杂度，并非技术上无法正确冻结它；原代码已示范了正确区分训练/推理模式。BN可能改变缩放适应性，但在推理时使用移动统计，不保证任意缩放严格不变。需在匹配分支上单独验证。

当前任务重构与每样本最近整体缩放的形状差RMS仅为原始输入RMS的0.626%/0.682%/0.687%。如果所有成分权重都等于s，重构严格等于s×输入；共享分类器可适应这类缩放，不一定需要学到有物理意义的分离。这个自由度原TASK也存在，其成功实验并不保证在新领域排除该行为。几何接近不能替代对分类效果的贡献诊断。

## 目前可说、不可说与下一步

可以说当前小网络/SSA表示/数据组合没有显示插件增量，而且起始输入分布改变、最终接近缩放是可复核的现象。不能说已经找到唯一失败原因，不能因为迁移了训练环节就声称完成原TASK复现，也不能因为此轮失败否定所有SSA或分类应用。

优先保持原先下一步：冻结当前分类器，用同一模型比较真实成分重构和“每样本最近整体缩放”的替代输入。之后若要恢复BN、改变特征保留方式或延长预算，一次只测试一个因素，并重新训练全部匹配对照，继续封存官方TEST。不能同时搬入EEGNet、改分解、加噪和加轮数后，将结果变化归因给其中一个。
