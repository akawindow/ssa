# 持续研究决策

## 2026-10-20：把基本有效性与跨模型迁移分开

用户确认：应先检验“选择器＋MLP”相对“原始输入＋相同训练预算MLP”的效果，再检验处理能否帮助独立预测器。此项是后续实验的优先级，不只是临时解释。

### 需要记住的区别

1. 下游任务目前是预测未来序列。MLP和Ridge是完成该任务的不同模型，不是两种不同任务。
2. 已有框架确实让MLP预测误差反向指导了SSA选择器，协同版本也更新共享特征；任务驱动机制已经实现。
3. 之前主要报告独立Ridge，是本工程为验证“可迁移的小插件”额外加入的检验，不能将它当成TASK训练的必要组成。
4. Ridge未受益只能说明尚未观察到对该独立模型的迁移收益，不能由此否定联合训练MLP的收益。
5. 联合MLP变好也不自动证明清洗成功，必须控制继续训练预算、固定/学习缩放等因素；原始观测没有干净真值。

### 当前主要比较

`原始历史 → 同一结构MLP` 与 `SSA成分 → 学习选择与重构 → 同一结构MLP`。

两组使用相同数据、同种子预训练权重、批次、代理优化器、代理更新次数和选检查点预算。这里“同一MLP”指同架构和共同初始化的匹配分支，各分支分别适配自己的输入，并非把一个只适应处理后输入的模型直接当成原始输入基线。

先回答联合模型有无受控收益；独立Ridge及其他预测器作为后续迁移问题单独报告。昨日持久性基线继续保留，避免把弱预测器上的增量写成有竞争力的预测方法。

### 下一轮执行方式

保持原始单变量数据和既有历史/预测长度。把原251条训练历史按时间拆成200条拟合与51条选检查点；原54条验证历史仅在本轮分支选定后评价。序列标准化只拟合200条拟合窗口对应的训练时段，不使用选检查点或评价时段。

重新训练共同MLP预训练状态，比较原始输入继续训练、固定0.5缩放、固定前七、学习全局尺度和全部SSA成分的任务选择。三个种子全部报告，不根据评价结果换分支或调预算。原54条历史以前已被查看，本轮不再用它选轮次，但仍不能称为从未使用过的独立确认集。

用户如后续调整任务、数据或目标，应追加决策并说明变化；历史记录保持原貌。

第九轮已按此优先级执行，见 [同MLP主比较](MLP_PRIMARY_RESULTS.md)。三个共同预训练＋15次匹配分支训练，200拟合/51选检查点/54评价；本轮不跑Ridge。任务选择器RMSE2148.83，同预算原始MLP2127.25，尚无稳定增量。该结果来自联合MLP主比较，不能与此前独立Ridge迁移的负结果混为一类。36项检查及18个保存模型的预测重载核验通过。
